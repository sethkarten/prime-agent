- The system prompt's session-role section (its terminal position) now states the turn-ending contract explicitly: ending a turn parks the session and every event wakes it (`[bash-done pid:N exit:M]`, `[agent-message from child:<name>]`, a heartbeat, each new user message), so multi-step work spans many short turns instead of one long hold; in-turn waiting (sleep calls, snapshot/poll loops, re-awaiting a running handle) is the anti-pattern the contract names. A prompt-guard test pins the contract in both daemon and daemonless wake modes.
