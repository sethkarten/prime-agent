Never run shell commands through `subprocess`, `os.system`, or a helper that wraps them, even when you need the output. Start the command with `h = bash(cmd)`; in a later `ipython` call, collect `r = await h` (this returns instantly if the command already finished) and use `r.output` and `r.exit_code`. Only commands that finish in under a second may be awaited inline; a longer one auto-backgrounds at the 10-second promotion window and returns a snapshot — end the turn right there and let the `[bash-done]` notification deliver the result. Never wait with `time.sleep` or a polling loop, and run long python compute as `bash("python script.py")` instead of pasting it into a cell.
